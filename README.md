
# Credit Card Default Analysis — SQL Project

## Overview

Analysis of 30,000 credit card clients to explore patterns associated with default payments, using SQL, SQLite, Python and pandas.

## Tools

- SQL
- Python
- pandas
- Google Colab

## Key Findings

- Lower credit-limit groups generally showed higher default rates.
- Default rates varied across education and age groups.
- Repeated positive repayment-status codes were strongly associated with higher default rates.
- Clients with positive delay codes in 3 or more months had a default rate of 59,99% compared with 11,71% for clients with no positive delay codes.

## Conclusion

Repayment history showed the strongest association with credit card default among the patterns examined.

## Dataset

UCI Machine Learning Repository — Default of Credit Card Clients.([https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients](https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients))
